# neotrade

Local-first paper-trading decision-support app for MacBook Neo (A18 Pro, 8GB).

**Status**: Session 0 complete — basic Python scaffold + CI.

## Quick Start

```bash
cd ~/dev/neotrade
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
pytest
```

See `docs/` for guides (TBD).

Local-only runtime.
